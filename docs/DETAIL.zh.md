# 便签滑动窗口上下文

DeepSeek Harness 默认用摘要回收上下文：会话超过压力阈值后，较早的一段历史被替换成一段模型写出的摘要。这意味着每次换窗都要多一次模型调用，而摘要保留什么由模型当场决定。

本插件把它换成滑动窗口加随身便签。

## 变化

装上之后摘要后端会被关掉，之后每一次换窗——自动压力触发、上下文溢出恢复、以及 `/compact`——都改为：

1. **保留窗口原文。** 最近一段对话原样保留，里面任何一个字都不会被改写。
2. **更早的内容收进一张便签。** 便签由被淘汰的消息确定性生成：目标、改动文件、执行过的命令、未解决的报错、下一步动作，以及模型主动钉下的内容。
3. **不发起模型调用。** 一次换窗不消耗 token，同一段历史永远生成同一张便签，重放会话得到一致结果。

被淘汰的消息没有被删除，它们仍留在会话日志里，仍可被会话检索和导出使用，只是不再发送给模型。

## 钉住的便签

便签无法凭空推断那些从没写下来的决策。插件为此提供一个模型可见工具 `sticky_note`，用来钉住必须跨换窗保留的短句——一个决策、一条约束、一个未决问题。被钉住的行会在每次换窗时原样带过去，后一次调用整体替换前一次。

你不必使用它。即便一条都没钉，便签仍然带着目标、改动过的文件、失败的命令和下一步动作，足够继续大多数工作。

## 你会看到什么

换窗是静默的。对话从便签加保留窗口继续，回复里不会提到这次切换。想查换窗事实时，会话日志把每次换窗记录成一对 `compaction/*` 事件，并记下被替换的范围。

## 配置

窗口大小沿用与自带后端相同的策略字段，已有的 `modelPolicies` 条目照常生效：

| 键 | 默认值 | 含义 |
|---|---|---|
| `thresholdRatio` | `0.8` | 触发换窗的消息预算占比。 |
| `retainRatio` | `0.35` | 原样保留的窗口占比。 |
| `retainTokens` | — | 按绝对大小保留窗口，与 `retainRatio` 互斥。 |
| `headroomTokens` | 自带默认值 | 计量压力前先从上下文窗口扣除的预留量。 |
| `noteMaxBytes` | `6144` | 便签本身的 UTF-8 字节预算。 |
| `noteTool` | `true` | 是否注册 `sticky_note` 工具。 |

段落预算（`objectiveMaxBytes`、`verifiedMaxBytes`、`openIssueMaxBytes`、`pinnedMaxBytes`）与列表上限（`fileListMax`、`commandListMax`、`objectiveMessages`、`pinnedLineMaxChars`）同样可配置；任何未知键会在加载时报错，而不是被静默忽略。

## 限制

- **便签记的是结构，不是散文。** 它记录历史里有什么——路径、命令、报错、最后一个请求和最后一次回复——而不是对推理过程的复述。凡是无法从这些事实复原的内容，请主动钉住。
- **不可分割的单个单元无能为力。** 一条独占窗口的超大工具结果或消息，无法靠换窗切开。
- **卸载本插件即恢复摘要后端**，因为切换是组合补丁，不是对已存会话的改写。
